# ACP-0002 — No governance token, ever

```
Number:   ACP-0002
Title:    No governance token, ever
Kind:     process
Status:   Draft
Created:  2026-11-17
Author:   the operator
Decision: (none yet)
```

## What it proposes

Add to the charter's prohibitions: AINRA never issues a token, coin or any transferable unit that carries a say in its
governance. Seats belong to accountable, identified parties (accredited registrars, operators of verifiers, witnesses,
public-interest members), never to whoever holds the most of something that can be bought.

## Why

Where governance weight can be bought, it has been. Votes bought with a single loan for a few seconds, proposals passed
at low turnout to move a treasury to the proposers, and a handful of holders with most of the votes are all on the
record for organisations run by token votes. A root whose value is that nobody can buy it cannot work that way.

## Open

This is a charter change, so it needs the operator's decision and an amendment record. Comments welcome.
