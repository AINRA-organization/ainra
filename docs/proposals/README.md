# AINRA Change Proposals

The register of proposed changes to AINRA. How it works: [../CHANGE-PROPOSALS.md](../CHANGE-PROPOSALS.md).

To propose a change, copy the header of any proposal below into `ACP-NNNN-short-name.md` with the next number, set
`Status: Draft`, and open a pull request. `make proposals-check` checks the form, nothing else.
